## Issues Found (ranked)

1. **🆕 Installer prints raw `\033` escapes (cosmetic)** — "Quick start" and "NEXT STEPS" blocks show literal `\033[1m`/`\033[0m`/`\033[2m` instead of styled text, while the rest of the script renders colors fine. Likely `echo` without `-e` in those blocks. Fix: use `printf` or `echo -e` consistently. First-impression polish only.
2. **🆕 CA cert lacks `basicConstraints=CA:TRUE` + `keyUsage` (compat, low-medium)** — `ca.pem` carries only a SAN extension. Browsers, curl/SecureTransport, and openssl CLI all accept the chain (verified live), but Python 3.14's strict verifier rejects it: `CA cert does not include key usage extension`. Impact scenario: a Python (or other strict-stack) backend calling a sibling service over `https://*.localhost` through the proxy — exactly the multi-service setup Antra sells. Suggested fix: add `basicConstraints=critical,CA:TRUE` + `keyUsage=critical,keyCertSign,cRLSign,digitalSignature` at CA generation (note: rotates the CA → existing keychain entries go stale, but the fingerprint-comparing trust check already handles that messaging correctly). Leaf certs are already well-formed (SAN, critical KU, EKU serverAuth, AKI).
3. **All three 0.2.7 nits — FIXED** ✅✅✅ (tty probe silent, port-busy fail-fast with pinned-command detection, hero `*` footnote).
4. **Prior holds** ✅ (open fallback URL, alias persistence, add single output, prune wording, run exit codes, arch mapping, 502/503 pages, replace guards, doctor labels).
5. **Observation, not an issue:** `prune` summary `All N route(s) alive` counts static/unchecked-backend routes as alive — fine given per-line `(static route, kept)` disclosure and prune's orphan-cleanup job.
