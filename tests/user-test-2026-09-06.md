# Antra UX Test — 2026-09-06

## Phase 1: Discovery (Website)

- **What does this tool do?** Local dev proxy that gives your apps stable HTTPS domains (like `myapp.localhost`) without ports, hosts file edits, or cert warnings.
- **What's the promise?** "One command" to get a real HTTPS URL for local dev. No config headaches.
- **Does the website make you want to try it?** Yes. Clear problem statement, comparison table is effective.
- **Confusing/unclear:** Nothing immediately confusing.
- **Questions before installing:** What permissions are needed? Is it safe?

## Phase 2: Installation

- **How smooth was the install?** Antra was already installed (`antra 0.1.0`). The install script URL on the website (`https://antra.iifelse.com/install.sh`) returns **HTML instead of a shell script** — still broken.
- **Did you feel confident it was safe to run?** N/A — already installed.
- **Any unnecessary/confusing steps?** The broken install URL remains a blocker for new users.

## Phase 3: First Run

- **`--help` output:** Clear, concise. Lists all 9 commands. Enough to get started.
- **`doctor` output:** Shows ✓/✗/⚠ symbols. "CA not trusted" — clear guidance. "Proxy daemon not running" — clear guidance. "Port 443/80 in use" — noted but doesn't block.
- **Could you figure out next steps?** Yes — `antra trust` then `antra proxy start`.

## Phase 4: Core Usage

- **`antra trust`:** Requires interactive confirmation. Failed with `SecCertificateAddToKeychain: Write permissions error` — needs sudo or keychain access.
- **`antra proxy start`:** Worked immediately. Daemon started on PID 6948, bound to 443/80.
- **`antra run --domain test.localhost -- command`:** Worked. Domain resolved, route registered.
- **`antra alias myapp.localhost 8080`:** Worked first try. Clear output.
- **`antra list`:** Clean table format when daemon running.
- **`antra proxy status`:** Shows PID, uptime, routes, socket path.
- **`antra proxy stop`:** Clean shutdown.
