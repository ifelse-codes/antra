# HTTPS / TLS Research

## Architecture

```
Antra Root CA (generated by rcgen)
    │
    ├── myapp.localhost (leaf cert, signed by CA)
    ├── api.myapp.localhost
    ├── myapp.test
    └── custom-domain.com
```

## CA Generation (rcgen)

```rust
use rcgen::{CertificateParams, KeyPair, IsCa, BasicConstraints};

let mut params = CertificateParams::new(vec!["Antra Local CA".to_string()])?;
params.is_ca = IsCa::Ca(BasicConstraints::Unconstrained);
let ca_key = KeyPair::generate()?;
let ca_cert = params.self_signed(&ca_key)?;

// Store: ~/.config/antra/ca.pem, ~/.config/antra/ca-key.pem
```

## Leaf Certificate Generation

Wildcard certs are INVALID for `.localhost` (TLS spec: wildcard can't cross TLD boundary).
Must generate per-hostname certificates on-demand via SNI callback.

```rust
use rcgen::{CertificateParams, KeyPair};

fn generate_leaf_cert(hostname: &str) -> Result<CertifiedKey> {
    let params = CertificateParams::new(vec![hostname.to_string()])?;
    let key = KeyPair::generate()?;
    let cert = params.signed_by(&key, &ca_key, &ca_cert)?;
    Ok(CertifiedKey::new(
        vec![cert.der().clone()],
        Arc::new(key.into()),
    ))
}
```

## TLS Termination (rustls)

```rust
use rustls::ServerConfig;
use rustls::crypto::ring::default_provider;

let config = ServerConfig::builder_with_provider(Arc::new(default_provider()))
    .with_safe_default_protocol_versions()?
    .with_no_client_auth()
    .with_cert_resolver(Arc::new(SniResolver::new()));
```

## SNI Resolver

```rust
struct SniResolver {
    cache: RwLock<HashMap<String, Arc<CertifiedKey>>>,
    ca_key: Arc<SigningKey>,
    ca_cert: CertificateDer<'static>,
}

impl ResolvesServerCert for SniResolver {
    fn resolve(&self, hello: ClientHello<'_>) -> Option<Arc<CertifiedKey>> {
        let sni = hello.server_name()?.to_str().to_string();

        // 1. Check memory cache
        if let Some(cert) = self.cache.read().get(&sni) {
            return Some(Arc::clone(cert));
        }

        // 2. Check disk cache
        if let Some(cert) = self.load_from_disk(&sni) {
            self.cache.write().insert(sni, Arc::clone(&cert));
            return Some(cert);
        }

        // 3. Generate new cert
        let cert = generate_leaf_cert(&sni, &self.ca_key, &self.ca_cert)?;
        self.save_to_disk(&sni, &cert);
        self.cache.write().insert(sni, Arc::clone(&cert));
        Some(cert)
    }
}
```

## Trust Store Management

### os-truststore crate

```rust
let ca = os_truststore::Cert::from_pem(&ca_pem_bytes)?;

match os_truststore::install(&ca) {
    Ok(Report::Installed) => println!("CA installed successfully"),
    Ok(Report::AlreadyInstalled) => println!("CA already trusted"),
    Ok(Report::InstalledNotTrusted { reason }) => {
        println!("CA added but not trusted: {reason}");
    }
    Err(TrustError::InteractiveAuthRequired) => {
        println!("macOS requires GUI authentication. Please approve the dialog.");
    }
    Err(TrustError::NeedsElevation { detail }) => {
        println!("Need admin/root: {detail}");
    }
    Err(TrustError::StoreToolMissing { hint }) => {
        println!("Missing tool: {hint}");
    }
    Err(e) => {
        println!("Trust error: {e}");
    }
}
```

### In-Process Trust (Alternative)

If system trust modification isn't needed, trust the CA only within Antra:

```rust
let roots = os_truststore::inprocess::rustls_root_store(&ca)?;
let config = rustls::ClientConfig::builder()
    .with_root_certificates(roots)
    .with_no_client_auth();
```
